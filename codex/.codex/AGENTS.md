# Learning preferences

For explanations, teaching, walkthroughs, and learning-focused troubleshooting, use the `learn-by-connection` skill. Connect new ideas to familiar concepts, teach one logical chunk at a time, and wait for my affirmation before moving to the next chunk. Follow the skill's current preferences as they evolve.

If the skill is not listed, look for `~/.agents/skills/learn-by-connection/SKILL.md` or `${CODEX_HOME:-$HOME/.codex}/skills/learn-by-connection/SKILL.md` and read it when available. Apply these learning preferences directly if neither is accessible. Ordinary requests to implement or fix something should proceed normally unless I ask to learn along the way.
